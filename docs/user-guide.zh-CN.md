## 工作原理

音源按 MIDI 通道接收弯音，同一个通道上的所有音符会一起弯。FL Studio 把一个乐器的所有音符都放在同一个通道上发送。Curvable 用两种方式解决这个问题：

- **音源副本（默认）。** Curvable 托管你的音源，并在需要时复制出更多副本。同一时刻弯音走向不同的音符由不同的副本演奏，于是每个副本的弯音只服务于一个音符。不弯音或弯音完全相同的音符共用一个副本。
- **MPE 模式。** 如果音源支持 MPE，Curvable 可以只用一个实例，把每个弯音的音符放在各自的 MIDI 通道上发送。

音符和曲线写在 Curvable 自己的钢琴卷帘里。Curvable 跟随宿主播放它们，由音源发出声音。

## 加载音源

点右上角的 **加载音源**。音源列表包括：

- 以前在 Curvable 里加载过的音源，最近用过的排在前面；
- FL Studio 已经扫描过的乐器（从 FL Studio 的插件数据库读取，不需要加载）。

输入文字可以搜索，单击音源或按 Enter 即可加载。也可以：

- 把 `.vst3` 文件，或 FL Studio 浏览器里的乐器，拖到 Curvable 上；
- 点 **浏览文件...** 选择 `.vst3` 文件；
- 打开 **插件管理器...** 扫描文件夹中的插件。

加载后，按钮会显示音源的名字。再次点击可以换成别的音源或卸载音源。音源及其设置会保存在工程里。

如果工程用到的音源在这台电脑上找不到，按钮会显示 **缺失：<名称>**。Curvable 会保留该音源保存的设置，在装有它的电脑上打开工程时不会丢失任何内容。

## 界面

顶栏包括：

- **钢琴卷帘 / 音源** 标签页。音源页显示托管音源自己的界面，可以像平常一样在这里编辑音色，Curvable 会把改动同步给每个副本。
- **AUTO / TRIGGER / OFF**，即[播放模式](#播放模式)。
- **MPE**，即 [MPE 模式](#mpe-模式) 开关，加载音源后出现。
- 音源按钮，同时显示正在运行的副本数（见[音源副本](#音源副本)）。
- 设置按钮（齿轮）。

钢琴卷帘左边是琴键，上方是标尺，中间是音符区，下方是力度栏（**VEL**）。底栏放着工具、**吸附**、**弯音**、**MIDI** 按钮和 **?**（全部鼠标和键盘操作）。底栏右侧的文字显示当前工具和选择下最常用的操作，以及需要注意的提醒。

拖动窗口右下角可以调整窗口大小。

## 播放模式

- **AUTO**：跟随宿主的时间线播放 Curvable 的音符。在 FL Studio 中，Curvable 所在的通道随它的 Pattern 或整首歌一起播放。FL Studio 自己的钢琴卷帘里给这个通道写的音符也会传给音源，但不带弯音。
- **TRIGGER**：通道收到音符时开始播放，例如来自 FL Studio 钢琴卷帘的音符或 MIDI 键盘。按住期间循环播放，触发用的音符本身不发声。可以用一个音符在 Pattern 里放置一整段 Curvable 乐句。
- **OFF**：不播放 Curvable 的音符。宿主发来的音符仍会传给音源。

## 编写音符

底栏有三个工具：**绘制**（P）、**曲线**（C）和 **切割**（S）。

使用 **绘制** 工具时：

- 单击空白处添加音符，按住继续拖动可以设置长度。新音符沿用上一次画出或调整过的音符长度。
- 拖动音符可以移动它的时间和音高。拖动音符右端可以改变长度。
- 右键单击音符将其删除，也可以按住右键拖过多个音符。
- 拖动时按住 **Alt**，移动或改变长度时不吸附。
- 单击琴键可以试听音高。

选择音符在任何工具下都可以使用：

- **Ctrl + 拖动** 框选。**Shift + 单击** 把音符加入选择或从选择中去掉。
- **Ctrl + A** 全选，**Esc** 取消选择。
- **Delete** 删除选中的音符。**Ctrl + C / X / V** 复制、剪切和粘贴（粘贴到鼠标所在位置）。**Ctrl + B** 或 **Ctrl + D** 把选中的音符复制一份接在后面。
- **↑ / ↓** 移调一个半音（按住 **Shift**：一个八度）。**← / →** 按吸附步长移动（按住 **Shift**：一小节）。
- **Ctrl + Z / Ctrl + Y** 撤销和重做。

力度：在 **VEL** 栏中拖动，或在音符上按住 **Alt** 滚动滚轮。音符处于选中状态时，整个选择一起改变。

**吸附** 设置音符和曲线节点的网格：小节、1/4 到 1/32、三连音或不吸附。

浏览：滚轮上下滚动，**Shift + 滚轮** 左右滚动，**Ctrl + 滚轮** 水平缩放，**Ctrl + Shift + 滚轮** 垂直缩放。也可以使用滚动条。

## 音高曲线

每个音符都有一条音高曲线，描述它随时间偏离自身音高的幅度。没有曲线的音符按原音高演奏。

使用 **曲线** 工具时：

- 单击音符添加节点，按住继续拖动来放置。节点吸附到半音和网格，按住 **Alt** 可以自由放置。
- 拖动节点可以移动它，拖动时会显示偏移的半音数。
- 两个节点之间有一个小圆圈。上下拖动它，可以把这一段从直线变成先慢后快或先快后慢的曲线。
- 右键单击节点将其删除。双击音符去掉整条曲线。
- 第一个节点之前，音符保持第一个节点的音高；最后一个节点之后，保持最后一个节点的音高。

在曲线工具中，弯过的音符会在原音高处显示一条细虚线作参照。

使用 **绘制** 工具时，选中音符的节点和手柄同样会显示，可以直接拖动，不用切换工具就能调整曲线。添加节点或使用右键菜单时，请切换到曲线工具。

超出弯音范围的节点显示为红色，见[弯音范围](#弯音范围)。

## 颤音与 Trill

用曲线工具右键单击音符：

- **此段加颤音**：在单击位置前后两个节点之间加上颤音。**整个音符加颤音**：作用于整个音符。
- **此段加 Trill** 和 **整个音符加 Trill**：在本音和相邻的音之间快速交替。
- **速度跟随曲速**：在 Hz 和音符时值之间切换速度的单位。
- **去掉颤音**（或 **去掉 Trill**）：从音符上去掉。设置会保留，下次加上时沿用。

一个音符同一时间只能有一种。在有颤音的音符上选择 Trill，它其他的颤音段也会一起变成 Trill。

设置直接在音符上调整，使用曲线工具（音符选中时也可以用绘制工具）：

- **菱形手柄。** 上下拖动改变深度。对 Trill 来说，这里设置的是相邻音的音程（半音）；拖到音符下方就是下方的音。左右拖动改变速度。第一次拖动的方向会一直保持到松开鼠标。
- **音符下方的小竖条**（仅颤音）。拖动它设置颤音渐入所用的时间。

默认值：颤音深度 0.4 个半音，速度 5.5 Hz，渐入半拍。Trill 默认和上方全音交替，每个三十二分音符换一次，速度跟随曲速。速度跟随曲速时，会吸附到 1/4、1/8、1/8T、1/16、1/16T 或 1/32；对 Trill 来说，这是每次交替的时值。

放大到足够大时，音符本身会画成带颤音的形状；否则颤音以波纹的形式画在音符上。

## 常用弯音与预设

右键菜单（曲线工具）里还有常用弯音：

- **下方滑入（Scoop）**：从下方滑入
- **越过回落（Overshoot）**：超过目标音高再回落
- **推弦再放回**：向上弯再回来
- **尾音下滑（Fall）**：在结尾向下滑
- **尾音上挑（Doit）**：在结尾向上挑

音头和音尾的弯音可以组合使用。对选中的音符使用时，会作用于整个选择。

**预设** 用来保存自己的曲线：

- **将曲线存为预设...**：把右键单击的音符的曲线（包括颤音或 Trill 的设置）保存在一个名字下。使用已有的名字保存会替换原来的预设。
- 在菜单中选择一个预设，即可套用到单击的音符，或所有选中的音符。节点位置按每个音符的长度伸缩，颤音速度不变。
- **删除预设**：删除一个预设。

预设由所有工程和所有 Curvable 实例共用，保存在 Curvable 设置文件夹的 `CurvePresets.xml` 中（Windows：`%APPDATA%\asahanada\Curvable`；macOS：`~/Library/Application Support/asahanada/Curvable`）。

## 滑音

选中两个以上的音符，按 **G**（或在右键菜单中选择 **滑音连成连奏音符**）。这些音符会合并成一个音符，从每个音高滑到下一个：

- 两个音符之间有空隙时，滑音填满这段空隙：从前一个音符的结尾开始，在后一个音符的起点到达。
- 音符首尾相接或重叠时，滑音最长用 1/4 拍，在下一个音符的起点到达。
- 音符上原有的曲线和颤音会保留在原来的位置。

如果选择中包含和弦，Curvable 会逐个声部地在和弦之间滑音，每个音配到下一个和弦里最近的音。下一个和弦的音较少时，几个声部会滑到同一个音；较多时，多出来的音单独开始。支持最多 12 个音的和弦。

如果滑音需要比当前更大的弯音范围，Curvable 会提示所需的范围。

## 切割

使用 **切割** 工具，单击音符就在该位置切开它，上下拖动可以切开竖线经过的所有音符。切点吸附到网格（按住 **Alt** 自由放置）。曲线保持完全不变。如果在滑音中间切开，后半段取最接近的半音作为音高，并从那里继续弯音，听起来和原来一样。

用切割工具可以把合并过的滑音重新拆成单独的音符。

## 弯音范围

底栏的 **弯音** 设置弯音轮向上和向下最多能弯多少个半音。它必须和音源里设置的弯音范围一致，否则所有弯音都会过大或过小。弯音范围保存在工程里。

请选择能覆盖曲线的最小范围，因为弯音轮的精度是分摊在整个范围上的。超出范围的曲线在演奏时会被截断，Curvable 会把它们标成红色并给出提醒。

在 [MPE 模式](#mpe-模式) 下，弯音必须和音源的 **MPE** 弯音范围一致，它通常与音色的普通弯音范围是分开设置的。

## 音源副本

Curvable 会计算工程需要多少个音源副本，在后台创建它们，并在不再需要的几秒后移除。音源按钮会显示数量，例如 **Serum 2 ×5（3 个运行中）**：

- **×5** 是副本数量。
- **（3 个运行中）** 是当前正在运算的数量。副本没有音符、输出静音 3 秒后会暂停，收到音符时立即恢复。主实例始终运行，导出渲染时也不会暂停。

副本创建期间，按钮会显示进度，例如 **(2/4)**。在它准备好之前，分配给它的音符暂时不带弯音演奏。

每个副本的音色都和主实例相同。参数的改动会立即同步；不经过参数的改动（例如在音源里换预设）会在稍后整体复制过去。如果某个副本听起来不同，可以在设置菜单中选择 **立即同步音源副本**。

最多 16 个音符可以同时各自弯音。超过之后，有的音符只能共用副本，重叠期间跟随最新那个音符的弯音。Curvable 会用红色虚线框标出这些音符并给出提醒。

Curvable 第一次使用副本时，会提醒你关掉音源自带的混响和延迟，因为每个副本都会各加一次。

## MPE 模式

对于支持 MPE 的音源，打开顶栏的 **MPE**。Curvable 会只用一个音源实例，把每个弯音的音符放在各自的 MIDI 通道上发送（通道 2 到 16，因此最多 15 个音符同时各自弯音）。

1. 在音源里打开 MPE。
2. 在 Curvable 中打开 **MPE**。如果弯音范围还是默认值，Curvable 会把它设为 48。
3. 确认 **弯音** 和音源的 MPE 弯音范围一致（通常是 48）。它通常和音色的普通弯音范围是分开设置的。

MPE 设置保存在工程里。

## MIDI 导入与导出

**导入：** 把 `.mid` 文件拖到卷帘上。音符从鼠标所在小节开始加入，并保持选中，可以马上移动。文件里的弯音会变成曲线。文件里保存了弯音范围时按文件读取（MPE 文件按 48），否则使用当前的弯音范围。也可以在 MIDI 按钮的菜单中选择 **从 MIDI 文件添加音符...**。

**导出：** 把 **MIDI** 按钮拖到 FL Studio（Playlist 或通道机架）、其他 DAW 或文件夹中。单击这个按钮，可以选择拖出时使用的格式，或保存文件：

- **每个声部一个通道**（默认）：每个声部使用自己的 MIDI 通道和音轨，带有各自的弯音和弯音范围。适合在宿主中用多个音源实例演奏。
- **MPE**：每个音符占用一个成员通道（2 到 16），弯音范围为 48。适合支持 MPE 的宿主和音源。

颤音和 Trill 会按当前速度写成弯音。如果有音符超出弯音范围，或只能共用通道，导出后 Curvable 会给出提醒。

## 自动化槽

FL Studio 只能自动化 Curvable 自己的参数，无法直接自动化托管在其中的音源。因此 Curvable 提供 16 个自动化槽，在 FL Studio 中显示为 **Slot 1** 到 **Slot 16** 这些参数。

在音源页右侧边缘的 **自动化** 手柄打开自动化槽：

1. 在某个槽上点 **学习**，然后转动音源里的一个旋钮。这个槽就关联到了该旋钮，FL Studio 中会显示为例如 **1 Cutoff**。
2. 像平常一样在 FL Studio 中自动化这个槽。所有音源副本上被关联的旋钮都会跟随。

点 **×** 取消关联。关联关系保存在工程里。

## 设置

齿轮按钮包括：

- **主题**：浅色或深色。
- **语言**：English、简体中文、日本語、한국어 或 Español，界面立即切换。
- **清除所有音符**。
- **立即同步音源副本**。
- **插件管理器...**：扫描插件，管理插件列表。
- **鼠标与键盘快捷键（F1）**。

主题和语言对所有工程生效。Curvable 把它们和插件列表、曲线预设一起保存在设置文件夹中。

## 常见问题

**弯音听起来过大或过小。** Curvable 的弯音范围和音源的弯音范围不一致，请把两者设成相同的值。MPE 模式下，请对照音源的 MPE 弯音范围。

**某个音符跟着别的音符一起弯。** 同时重叠的、弯音走向不同的音符超过了 16 个（这些音符带红框），或者新的音源副本还在创建中。请减少重叠，或在添加弯音后稍等片刻。

**声音比单独使用音源时更响，或混响更重。** 音源内置的效果在每个副本上都加了一次。请在音源里关掉它们，改用宿主的效果器。

**各个副本听起来略有不同。** 自由运行的 LFO 或随机的振荡器相位在各个副本之间不一致。请在音源中打开重触发；换预设后也可以选择 **立即同步音源副本**。

**CPU 占用高。** 每个有音符的副本都在运行一个完整的音源。同时弯向不同方向的音符越少，需要的副本越少；空闲的副本会自动暂停。对于支持 MPE 的音源，MPE 模式只需要一个实例。

**列表里找不到某个音源。** 在 FL Studio 或 Curvable 的 **插件管理器...** 中扫描它，或直接把它的 `.vst3` 文件拖到 Curvable 上。

**提示"无法再创建音源副本"。** 音源拒绝再加载一个实例，例如受授权或内存所限。Curvable 会自动重试，在此期间受影响的音符不带弯音演奏。
